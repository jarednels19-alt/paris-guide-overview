# paris-guide-overview
open one file and have the trip laid out visually - interactive Paris map with pins for hours, approximate price, ideal time of day, booking requirements, and a practical tip. Filter the map across 7 categories: Landmarks &amp; Views, Museums &amp; Culture, Parks &amp; Gardens, Food &amp; Cafés, Sweets &amp; Shopping, Experiences &amp; Walks, and Evening Out.
